## 언제 사용합니까

사용자가 로컬 파일을 선택하고 선택 목록에서 제거할 수 있게 할 때 사용하십시오.

## 언제 피해야 합니까

네트워크 업로드, 진행률, 서버 검증을 이 컴포넌트에 넣지 마십시오. 선택된 files를 소비자 코드에서 처리하십시오.

## 합성 구조

`Root > Trigger + List`를 사용합니다. Root의 files와 onFilesChange로 로컬 선택 상태를 제어할 수 있습니다.
