사용자와 채팅으로 대화하듯 현재 상황과 다음 행동을 전달합니다. 아래 규칙은 기본값이며,
사용자 목표와 대화 맥락에 맞게 적용합니다. 브랜드 말투, 도메인 용어와 실제 정책은 소비
프로젝트에서 정합니다.

## 말투를 일관되게 사용합니다

`-습니다`, `-해요` 등 프로젝트의 성격에 맞는 말투를 정하고 일관되게 사용합니다.
`-해요`체를 기본으로 사용합니다.

## 문장과 시각 맥락의 중복을 줄입니다

문장 안에서 반복되는 명사와 표현을 정리합니다. 페이지·패널·섹션·카드의 제목과 설명을
함께 읽고, 사용자가 이미 아는 맥락을 레이블과 버튼에 되풀이하지 않습니다.

| 맥락                            | 수정 전                                                        | 수정 후                                        |
| ------------------------------- | -------------------------------------------------------------- | ---------------------------------------------- |
| 같은 문장에서 대상 반복         | 생체인증 정보가 변경되어 생체인증 정보를 다시 등록해야 합니다. | 생체인증 정보가 변경되어 다시 등록해야 합니다. |
| `복구 코드` 카드의 버튼         | 복구 코드 재발급                                               | 재발급                                         |
| 자신의 프로필을 관리하는 페이지 | 본인 프로필 이미지                                             | 프로필 이미지                                  |

생략 후에도 대상과 행동을 식별할 수 있어야 합니다. 관리자가 여러 사람의 프로필을 다루는
화면에서는 소유자를 표시합니다. 여러 카드에 `재발급` 버튼이 있으면 스크린 리더에서도
대상을 구별할 수 있도록 카드 제목과 버튼을 `aria-labelledby` 등으로 연결합니다.

전달할 내용을 직접 씁니다. `~보다` 같은 형식으로 불필요한 반대 사례를 끌어와 설명하지
않습니다. 사용자가 실제 선택지를 비교해야 하는 경우에는 판단에 필요한 차이를 설명합니다.

## 자연스럽고 직접적으로 말합니다

| 기준                   | 수정 전                              | 수정 후                            |
| ---------------------- | ------------------------------------ | ---------------------------------- |
| 능동적이고 간단한 표현 | 카드론 평균 금리가 13%로 높아졌어요. | 카드론 평균 금리가 13%로 올랐어요. |
| 가능한 다음 행동       | 지금 버전에서는 쓸 수 없어요.        | 앱을 업데이트해 주세요.            |
| 받을 수 있는 혜택      | 계좌 개설 혜택은 받을 수 없어요.     | 4.5% 금리 혜택만 받을 수 있어요.   |
| 짧은 사유              | 가입할 수 없어요.                    | 부모님 허락이 필요해요.            |
| 적당한 경어            | 해지하시겠어요?                      | 해지할까요?                        |
| 간단한 질문            | 계좌를 가지고 계시나요?              | 계좌가 있나요?                     |
| 직접적인 동사          | 여쭤볼게요.                          | 확인할게요.                        |
| 쉬운 일상어            | 이자 환불을 받았어요.                | 이자를 돌려받았어요.               |
| 구체적인 생활 맥락     | 내일 결제될 예정이에요.              | 내일 카드값 나가는 날이에요.       |
| 자연스러운 조사        | 잔액 부족                            | 잔액이 부족해요.                   |

수동형 문장을 최소화하고 불필요한 경어와 어려운 한자어를 풀어 씁니다. 맞춤법·조사·띄어쓰기를
확인하고, `예정이에요`, `날이에요`, `업데이트해 주세요`처럼 표기합니다.

긍정형 안내에는 실제 가능한 행동과 조건을 담습니다. 위 예문은 업데이트로 기능을 사용할 수
있고, 해당 금리 혜택을 받을 수 있으며, 부모님 허락이 가입 조건인 상황을 전제로 합니다.
원인을 모를 때는 이유를 만들어 붙이지 않습니다. `카드값`은 카드 대금 결제일을 안내하는
맥락에 사용하고, 문의가 필요한 상황에서는 질문 자체를 생략하지 않습니다.

## 의미와 행동 결과를 보존합니다

강조가 필요하면 대상과 단어를 반복할 수 있습니다. 탈퇴 확인처럼 손실 범위를 이해해야 하는
화면에서는 서비스 이름과 영향을 명시합니다.

| 맥락                  | 수정 전                        | 수정 후                                                  |
| --------------------- | ------------------------------ | -------------------------------------------------------- |
| 탈퇴 대상과 손실 강조 | 탈퇴하면 모든 혜택을 잃습니다. | OO 서비스를 탈퇴하면 할인을 포함한 모든 혜택을 잃습니다. |

사용자가 결과를 예측하는 데 필요한 부정문은 유지합니다. `재발급하면 기존 복구 코드는 사용할 수
없어요.`처럼 효력이 사라지는 대상을 분명히 알려야 합니다. 긍정형으로 바꾸면서 손실·제약·복구
불가능 여부를 감추지 않습니다. 실제 정책이 모든 혜택의 소멸을 뜻할 때만 위 탈퇴 예문을 적용합니다.

## 문구를 화면 안에서 검토합니다

- 문장과 인접한 제목·설명·버튼에 불필요한 반복이 없는지 확인합니다.
- 생략한 대상과 행동을 시각 맥락 및 보조 기술로 식별할 수 있는지 확인합니다.
- 사용자에게 필요한 사실·짧은 사유·다음 행동이 있는지 확인합니다.
- 능동적 표현, 적당한 경어, 일상어, 맞춤법과 띄어쓰기를 확인합니다.
- 줄이거나 긍정형으로 바꾼 문구가 조건·손실·강조할 의미를 보존하는지 확인합니다.
