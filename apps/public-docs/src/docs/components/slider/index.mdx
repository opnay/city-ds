## 사용 기준

연속적인 수치 범위에서 대략적인 값을 빠르게 조정할 때 사용하십시오. 정확한 숫자 입력이나 증감이 중요한 경우에는 NumberInput을 사용하십시오.

## 폼

`name`을 Root에 전달하면 폼 제출에 연결됩니다.

## 바로 선택 값

`Track` 안에 `Indicator`와 함께 `<Slider.Anchor value={40} />`을 배치하면 40 위치에 작은 점이 표시됩니다. 호버하거나 키보드로 포커스하면 지정 값을 확인할 수 있고, 클릭하거나 Enter·Space로 선택하면 해당 값으로 이동합니다. 범위 Slider에서는 가장 가까운 비활성화되지 않은 핸들이 이동하며, 핸들 사이 최소 간격을 위반하는 선택은 적용되지 않습니다.

Anchor 값은 `min`부터 `max` 사이에서 `step`에 맞춰 지정하십시오. 범위를 벗어나거나 증감 단위에 맞지 않는 Anchor는 표시하지 않습니다. Anchor도 Base UI의 입력 경로를 사용하므로 `onValueChange`·`onValueCommitted`에는 `input-change` 사유가 전달됩니다.

전체 입력을 잠글 때는 `Root disabled`를 사용하십시오. Thumb을 개별적으로 잠그는 구성에서는 선택 가능한 핸들이 없을 때 Anchor에도 `disabled`를 전달하십시오.

## 값 툴팁

각 Thumb은 호버·키보드 포커스·드래그 중 자신의 현재 값을, Anchor는 호버·키보드 포커스 중 지정 값을 표시합니다. Root의 `format`·`locale`을 따르며, 각 `tooltip={false}`로 생략할 수 있습니다.

## 접근성

각 Thumb에 값의 의미가 드러나는 `aria-label` 또는 `getAriaLabel`을 제공하십시오. 범위 Slider에는 두 thumb을 구분하는 이름을 사용하십시오.
