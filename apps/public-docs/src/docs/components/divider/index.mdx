## 접근성

Divider는 기본 가로 `separator`이며 `orientation="vertical"`로 세로 구분선을 만듭니다.
세로형은 부모 영역의 높이를 따르므로 높이가 정해진 레이아웃 안에 사용하십시오.

children은 가로 구분선의 가운데 라벨이며 접근 가능한 이름으로도 사용합니다. 세로형에는 children을 전달하지 마십시오. `plain`은 가로 라벨의 강조만 낮춥니다.
외부 제목으로 구분선을 설명하면 `aria-labelledby`로 연결하십시오.
