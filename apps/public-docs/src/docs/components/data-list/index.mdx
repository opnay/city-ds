## 사용 기준

DataList는 계정 정보, 연결된 앱의 권한, 설정 요약처럼 이름과 값을 읽는 화면에 사용하십시오.
같은 열을 가진 여러 레코드를 비교하려면 Table을, 시간순 이벤트 목록에는 ul 또는 ol을 사용하십시오.

## 접근성

`Root`는 `dl`, `Item`은 `div`, `Label`은 `dt`, `Value`는 `dd`를 렌더링합니다.
각 Item 안에 Label과 Value를 순서대로 배치하십시오. Label은 이름을 설명하는 요소이며 입력의 label이 아닙니다.
이 컴포넌트는 입력 후보를 제공하는 HTML `datalist`와는 용도가 다릅니다.
값에 입력을 넣는 경우 Field.Label 등으로 입력의 접근성 이름을 별도로 연결하십시오.

## 배치

가로 배치는 이름 열을 맞추고, 24rem 미만의 컨테이너에서는 이름 아래로 값을 배치합니다.
긴 텍스트는 줄바꿈하며, 값 안에 배지·링크·목록·버튼을 조합할 수 있습니다.
배경과 외곽 테두리는 부모 Panel 등에서 구성하십시오. 빈 값은 항목을 빼거나 “없음”처럼 의미를 명시하십시오.

`render`로 합성할 때는 dl → div → dt·dd의 의미 구조를 유지하십시오.
구조의 근거는 [HTML description list 표준](https://html.spec.whatwg.org/multipage/grouping-content.html#the-dl-element)에서 확인할 수 있습니다.
