## 조합

`Field`는 입력 UI가 아니라 하나의 폼 제어에 Label, Description, Error, disabled, invalid
문맥을 연결하는 컴포넌트입니다.

| 제어                                 | Label 조합                                      |
| ------------------------------------ | ----------------------------------------------- |
| Input, Textarea, NumberField, Select | 외부 `Field.Root`와 `Field.Label`을 사용합니다. |
| 입력형 Combobox                      | 외부 `Field.Root`와 `Field.Label`을 사용합니다. |
| SearchField, DateField, DatePicker   | 자체 Label, Description, Error를 사용합니다.    |

Input과 Textarea는 `Field.Root` 안에 직접 배치하십시오. `Field.Control`은 일반 Input 대신
사용하는 래퍼가 아니라, 사용자 정의 제어를 Field 문맥에 합성할 때 사용합니다.

## 접근성

Label을 생략하지 마십시오. Description과 Error는 제어의 설명 관계에 연결되어야 합니다.
