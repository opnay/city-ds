## 언제 사용합니까

설정, 도움말, 작업 전제처럼 본문 흐름 안의 보조 안내를 강조할 때 사용하십시오.

## 언제 피해야 합니까

새로 발생한 오류를 알리는 용도로만 사용하지 마십시오. 그 경우 Alert의 의미를 먼저 검토하십시오.

## 합성 구조

Callout은 Alert의 의미상 별칭이며 `Root`, `Title`, `Description`, `Action`과 tone·appearance 계약을 동일하게 사용합니다.
