## Label 조합

`Combobox.Input`을 사용하는 입력형 Combobox는 외부 `Field.Root` 안에서
`Field.Label`과 `Combobox.Root`를 형제로 배치하십시오. 입력 없이 Trigger로 여는
선택형 Combobox에는 `Combobox.Label`을 사용합니다.

## 접근성

Label을 제공하고 결과 없음에는 `Empty`를 넣으십시오. 선택 항목은 ItemIndicator로도 확인할 수 있어야 합니다.
