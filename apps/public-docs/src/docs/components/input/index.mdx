## Field 조합

Input과 Textarea는 가장 가까운 `Field.Root` 문맥을 자동으로 인식합니다. Label, 설명,
오류가 필요하면 `Field.Root` 안에 직접 배치하십시오. `Field.Control`로 다시 감싸지
마십시오.

## 입력 그룹 합성

접두 텍스트·단위처럼 값에 붙는 요소는 `InputGroup.Addon`으로 배치하십시오.
비밀번호 보기·숨기기처럼 독립적으로 조작하는 말단 버튼은 `InputGroup.Root`의 직접 자식으로 둡니다.
`SearchInput.Submit`과 같이 입력과 같은 size의 폭, 프레임 안쪽 전체 높이, 직선 모서리와 내부 구분선을 적용하십시오.
입력과 버튼의 테두리를 각각 중첩하지 않고, 포커스·오류·비활성 상태는 전체 프레임에 표현합니다.

## 접근성

placeholder는 label을 대신하지 않으므로 Field.Label 또는 aria-label을 제공하십시오.
