## Field 조합

DateInput은 날짜 값을 입력하는 제어입니다. 레이블, 설명, 오류가 필요하면 외부 `Field.Root`로
감싸고 `Field.Label`, `Field.Description`, `Field.Error`를 함께 배치하십시오.

## 접근성

날짜 형식을 `Field.Description`으로 알려 주고, 오류는 `Field.Error`로 제어와 연결하십시오.
