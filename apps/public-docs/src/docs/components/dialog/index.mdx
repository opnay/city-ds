## 모션

Popup은 아래로 3% 이동한 opacity 0·0.97 scale 상태에서 120ms 동안 위로 나타나며 닫힐 때 같은 경로로 돌아갑니다. Backdrop은 8px blur와 함께 같은 시간 동안 전환됩니다. 모션 감소 설정에서는 전환을 생략합니다.
