# city-ds

Base UI의 접근 가능한 동작과 Tailwind CSS의 토큰 기반 스타일을 결합한 개인용 React 디자인
시스템입니다. 운영 도구와 대시보드에 어울리는 절제된 모노크롬 표현을 기본값으로 삼습니다.

## 설치

아직 외부 레지스트리에는 배포하지 않습니다. 이 모노레포에서는 workspace 의존성으로 연결합니다.

```json
{
  "dependencies": {
    "@opnay/city-ds-react": "workspace:*"
  }
}
```

애플리케이션 진입점에서 패키지 CSS를 한 번 불러오십시오.

```tsx
import '@opnay/city-ds-react/styles.css';
import { Button } from '@opnay/city-ds-react/button';

export function SaveButton() {
  return <Button>Save changes</Button>;
}
```

`styles.css`는 Tailwind Preflight, city-ds 토큰과 컴포넌트 유틸리티를 포함하는 앱 기반
스타일입니다. 애플리케이션 루트에서 한 번만 불러오십시오. 리셋 없이 토큰만 필요한 경우에는
CSS 변수 전용 `@opnay/city-ds-react/theme.css`를 사용할 수 있습니다.

## 디자인 토큰

공개 토큰은 모두 `--city-` 접두사의 CSS 변수입니다. 색상·간격·타이포그래피·radius·
그림자·모션·컨트롤 크기를 제공하며, Tailwind 유틸리티와 컴포넌트도 같은 값을 사용합니다.

```css
.dashboard-card {
  padding: var(--city-space-6);
  color: var(--city-color-foreground);
  background: var(--city-color-surface);
  border-radius: var(--city-radius-lg);
  box-shadow: var(--city-shadow-panel);
}
```

전체 목록과 테마별 미리보기는 `기초/디자인 토큰` 스토리에서 확인할 수 있습니다.

## 테마

기본값은 운영체제 설정을 따릅니다. 강제로 고정하려면 문서 루트에 `data-theme`을 지정하십시오.

```ts
document.documentElement.dataset.theme = 'dark';
document.documentElement.dataset.theme = 'light';
delete document.documentElement.dataset.theme; // system
```

상단 툴바에서도 `system`, `light`, `dark`를 전환해 모든 스토리를 확인할 수 있습니다.

## 공개 API

- 단일 패키지 `@opnay/city-ds-react`에서 전체 API와 컴포넌트별 subpath를 모두 제공합니다.
- React 18.3과 19를 peer 범위로 지원합니다.
- Base UI의 `render` 계약을 유지하므로 기본 요소를 링크나 사용자 컴포넌트로 바꿀 수 있습니다.
- Vite와 Next.js App Router 소비 앱을 CI에서 프로덕션 빌드합니다.

현재 패키지는 개인 사용을 위한 `private`·`UNLICENSED` 상태입니다.
