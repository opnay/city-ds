## 접근성

Avatar.Image에는 사람이나 콘텐츠를 설명하는 `alt`를 제공하십시오. 이름이 바로 옆에 있어 이미지가 장식이면 빈 `alt`를 사용하십시오.

Avatar.Fallback에는 이미지가 없거나 실패했을 때 식별할 수 있는 이니셜 또는 대체 콘텐츠를 넣으십시오. 로딩 지연을 표시해야 하면 `delay`를 사용하십시오.

`shape="circle"`은 사람 프로필처럼 원형 식별에, `shape="square"`는 서비스·콘텐츠 아이콘처럼 모서리가 작은 사각형 식별에 사용하십시오.
