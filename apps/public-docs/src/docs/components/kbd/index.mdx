## 접근성

Kbd는 기본적으로 native `kbd` 요소를 사용해 키나 단축키 표기를 전달합니다. 실행 요소나
키보드 이벤트 처리를 대신하지 않으며, 운영체제에 따른 표기 변환도 수행하지 않습니다.

단축키가 화면의 다른 설명 없이 전달되면 `aria-label`로 읽을 이름을 제공하십시오. 여러 키를
조합할 때 각 Kbd를 단축키 설명 안에 함께 배치해 관계를 읽을 수 있게 하십시오.
