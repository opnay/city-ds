## 조건 조합

검색어·상태·기간처럼 하나 이상의 조건을 함께 배치합니다. 각 조건의 레이블과 입력은
`Field.Root` 또는 하나의 컨테이너로 묶으십시오. FilterBar는 가용 폭에 따라 조건별 열을
배분하며, 좁은 영역에서는 줄바꿈합니다. 액션은 조건 뒤에 배치됩니다.

조건 값, AND·OR 조합, 즉시 적용·제출 시점과 데이터 조회는 소비자가 소유합니다.
위 예제는 이름과 상태를 AND로 즉시 적용하며 초기화하면 두 조건을 모두 되돌립니다.
