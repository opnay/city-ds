# Content Text

Content Text는 페이지 제목, 섹션 제목, 문장과 문단처럼 컴포넌트 밖에서 읽는 텍스트의
역할과 리듬을 정의합니다. 의미 있는 HTML 요소를 먼저 선택하고 `city-text-*` 클래스로 시각
역할을 적용하십시오. Button·Input·Badge 같은 컴포넌트 내부 텍스트는
[Control Text](?path=/docs/디자인-패턴-typography-control-text--docs) 계약을 따릅니다.

`display`와 `page-title`만 viewport에 따라 정해진 범위 안에서 유동적으로 바뀝니다. 역할
클래스는 글꼴, 크기, 행간, 굵기와 자간만 정합니다. 색상과 외부 여백은 정보 의미와
레이아웃에서 별도로 선택하십시오.

## 문단 흐름

`city-prose`는 68ch 읽기 폭, 16px 흐름 간격, 제목 전 추가 간격, 목록 들여쓰기와 긴 문자열
줄바꿈을 제공합니다. 하위 요소의 텍스트 역할은 자동으로 정하지 않습니다.

## 적용 순서

1. 문서 구조에 맞는 `h1`–`h6`, `p`, `figcaption` 같은 의미 요소를 먼저 선택합니다.
2. 화면과 영역의 정보 위계에 맞는 `city-text-*` 역할을 적용합니다.
3. 여러 문단의 읽기 흐름이 필요할 때만 부모에 `city-prose`를 추가합니다.
4. 색상, 정렬과 여백은 해당 정보의 의미와 레이아웃 규칙으로 정합니다.

## 검토 기준

1. heading 수준이 글자 크기가 아니라 문서 구조를 따릅니까?
2. 같은 역할의 크기, 행간, 굵기가 화면마다 일치합니까?
3. 일반 문단이 `city-text-body`와 읽기 쉬운 폭을 사용합니까?
4. 긴 한글·영문·URL이 글자 크기를 줄이지 않고 안전하게 줄바꿈합니까?
5. 오류와 필수 안내를 `caption` 크기나 낮은 대비로 약화하지 않습니까?
6. 정보 위계를 색상만으로 표현하지 않습니까?
