# Radius

Radius는 atom·molecule의 **Shape 축**에서 외곽 크기와 모서리 곡률의 관계를 정합니다.
Surface의 채움·외곽선 방식이나 컴포넌트 타입이 아니라, 최종 border-box 높이와 형태의 의미로
radius를 선택하십시오.

padding·line-height·border는 최종 높이를 만드는 입력값입니다. 같은 외곽 높이라면 내부 padding이나
아이콘 유무가 달라도 동일한 radius를 사용해야 합니다.

높이는 padding과 border를 포함한 border-box를 의미합니다. 텍스트·아이콘에 맞춰 padding을
조정하더라도 최종 높이 단계가 유지되면 radius를 바꾸지 마십시오.

## 컴포넌트 매핑

- Checkbox `14/16/20px`는 compact rectangle인 `xs`를 사용합니다.
- Badge label `20/24/28px`는 각각 `xs/sm/sm`을 사용합니다.
- Button·ToggleGroup.Item·Outline Frame `24/28/32/36/40px`는 모두 `sm`을 사용합니다.
- Count·dot Badge, Radio, Switch는 형태 자체가 수량·선택·전환 상태를 나타내므로 `full`을
  사용합니다.

## 축 분리 규칙

- `solid`, `subtle`, `outline`, `ghost`는 Surface를 바꾸지만 Shape를 바꾸지 않습니다.
- `primary`, `destructive` 같은 tone도 높이와 radius에 영향을 주지 않습니다.
- focus·hover·active·checked 상태는 색·stroke·fill을 바꿀 수 있지만 geometry를 바꾸지 않습니다.
- Popup·Panel 같은 container surface는 원자형 높이 규칙의 대상이 아니며, 자체 크기·계층에 맞는
  container radius를 사용합니다.

## 검토 기준

1. radius가 padding이 아니라 최종 border-box 높이에서 결정됩니까?
2. 같은 높이의 직사각형 원자 컴포넌트가 동일한 곡률을 사용합니까?
3. Surface·tone·상태 변경 전후에 높이와 radius가 유지됩니까?
4. `full`은 단순 장식이 아니라 pill·circle 의미가 있을 때만 사용합니까?
5. container와 내부 행 hover 면을 원자형 높이 규칙에 억지로 포함하지 않았습니까?
