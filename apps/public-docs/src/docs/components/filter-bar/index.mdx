## 조건 조합

FilterBar는 Table이나 목록 결과 바로 위에서 검색어·상태·기간을 좁히는 조건 행입니다.
표면, 테두리, 바깥 padding을 만들지 않습니다. Table의 첫·마지막 열과 맞출 inline gutter는
주변 데이터 영역이 소유합니다. 별도 조회 영역에는 [FilterPanel](/components/filter-panel)을 사용하십시오.

각 직접 자식은 하나의 조건으로 취급하며, 내용에 필요한 너비를 유지합니다.
레이블과 입력은 `Field.Root` 또는 하나의 컨테이너로 묶으십시오. 화면이나 컨테이너의
가용 폭이 부족할 때만 조건과 액션이 순서대로 줄바꿈합니다. 균등한 열로 늘리지 않습니다.

조건 값, AND·OR 조합, 즉시 적용·제출 시점과 데이터 조회는 소비자가 소유합니다.
위 예제는 이름과 상태를 AND로 즉시 적용하며 초기화하면 두 조건을 모두 되돌립니다.
