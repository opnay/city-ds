# Motion

Motion은 상태 변화의 방향, 결과와 공간 관계를 설명하는 패턴입니다. 장식적인 움직임보다 사용자가
무엇이 바뀌었는지 예측할 수 있게 하는 것을 우선합니다.

기본 transition은 `--city-duration-normal`과 `--city-easing-standard: ease-in-out`을 사용합니다.
Tailwind에서 단계를 명시할 때는 `duration-(--city-duration-fast)`처럼 public token을 직접
참조합니다. Density와 Control Size는 duration을 자동으로 바꾸지 않습니다.

## Easing 계약

- 기본 상태 변화는 `ease-in-out`을 사용합니다.
- 열기·닫기처럼 왕복하거나 중간에 취소할 수 있는 전환은 진행값이 목적지를 넘거나 역방향으로
  움직이면 안 됩니다.
- bounce·spring은 공통 토큰으로 제공하지 않습니다.
- 되돌아가지 않는 일회성 완료 피드백에서만 프로젝트 패턴으로 검토합니다.
- 중간 취소가 가능한 컴포넌트는 keyframe animation보다 CSS transition을 우선합니다.

## 고유 크기 전환

Accordion처럼 콘텐츠 높이를 미리 알 수 없는 영역은 임의의 `max-height`를 사용하지 않습니다.
Grid track을 `0fr`과 `1fr` 사이에서 전환하고 직접 자식이 축소될 수 있도록 `min-height: 0`을
적용합니다.

```css
.Panel {
  display: grid;
  grid-template-rows: 1fr;
  transition:
    grid-template-rows var(--city-duration-slow) var(--city-easing-standard),
    padding-bottom var(--city-duration-slow) var(--city-easing-standard);
}

.Panel[data-starting-style],
.Panel[data-ending-style] {
  grid-template-rows: 0fr;
  padding-bottom: 0;
}

.PanelContent {
  min-height: 0;
  overflow: hidden;
}
```

## Reduced motion

`prefers-reduced-motion: reduce`에서는 이동, 크기 변화와 반복 애니메이션을 제거합니다. 최종 상태,
포커스, 선택과 진행 결과는 애니메이션 없이도 즉시 구분되어야 합니다.

## 책임 경계

- city-ds는 Control 상태, open·close, loading과 swipe처럼 컴포넌트가 소유한 모션을 정의합니다.
- 프로젝트는 페이지 전환, 목록 재배치, 업무 완료 피드백과 여러 컴포넌트의 연속 동작을 정의합니다.
- 프로젝트 모션이 컴포넌트의 상태 의미와 reduced-motion 동작을 덮어쓰면 안 됩니다.
