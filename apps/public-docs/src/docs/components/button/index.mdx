## 언제 사용합니까

저장, 생성, 적용처럼 사용자가 의도적으로 실행하는 명령에 사용하십시오. 링크로 이동하는
행동도 버튼 모양이 필요하면 `render`로 실제 링크를 합성하십시오.

## 언제 피해야 합니까

켜짐 상태가 유지되는 선택에는 Toggle이나 Switch를 사용하십시오. 한 그룹에서 여러 primary
버튼을 두거나 크기로 우선순위를 표현하지 마십시오.

## 합성 구조

Button은 기본적으로 네이티브 `button`을 렌더링합니다. 링크로 바꿀 때는
`nativeButton={false}`, `role="link"`, `render={<Link />}`를 함께 사용합니다. 아이콘만 있는
버튼에는 `iconOnly`와 접근 가능한 이름을 반드시 제공하십시오.

## 접근성

- 버튼 문구는 `확인`보다 `변경사항 저장`처럼 결과를 예측할 수 있게 작성하십시오.
- 아이콘 전용 버튼에는 `aria-label` 또는 `aria-labelledby`를 제공하십시오.
- 비활성 버튼으로 조건을 숨기지 말고 가까운 설명을 `aria-describedby`로 연결하십시오.
- 링크 역할은 네이티브 링크로 유지해 새 탭 열기와 주소 복사를 지원하십시오.
