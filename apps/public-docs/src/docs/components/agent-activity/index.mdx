## 사용 기준

Thinking, 모델 변경, 작업 중단 등 짧은 상태를 같은 구조로 표시합니다.
이벤트 종류는 고정되어 있지 않으며 아이콘·문구·시간을 children으로 구성합니다.
상세를 펼치는 기능은 제공하지 않습니다. 입력·결과·오류 상세는 Actioned에 구성하십시오.
pending은 기본 로더 표시만 제어하며 실행이나 데이터 요청을 시작하지 않습니다.
각 part는 render 합성과 ref, className, 이벤트와 ARIA 속성을 지원합니다.

## 접근성

과거 이벤트는 자동 낭독하지 않습니다. 현재 진행 상태가 필요한 경우 소비자가 `role="status"` 또는 `aria-live="polite"`를 지정하십시오.
Indicator는 기본적으로 보조 기술에서 숨겨지므로 진행·중단 의미를 Content에도 표시하십시오.
기본 진행 애니메이션은 모션 감소 설정에서 멈춥니다. 사용자 아이콘의 애니메이션도 같은 설정을 존중하십시오.
