## 사용 시점

Meter는 저장 용량, 점수, 할당량처럼 정해진 범위 안의 현재 측정값을 표시합니다.
작업의 진행 상태나 완료 예상 시간을 나타낼 때는 Progress를 사용하십시오.

## 범위와 색상

`ranges`에는 `from`, `to`, `label`, `color`를 지정합니다. `from`은 포함하고 `to`는
제외하지만, Root의 `max`와 같은 `to`는 포함합니다. 겹치는 범위는 선언 순서가 앞선
범위가 우선합니다. 숫자가 아니거나 `from >= to`인 범위는 무시합니다.

범위를 생략하거나 값이 어느 범위에도 속하지 않으면 기본 primary 색상을 사용합니다.
이때 `Meter.RangeLabel`은 렌더링하지 않습니다. 범위의 `color`에는
`var(--city-color-success)`처럼 CSS 색상 값을 전달할 수 있습니다.

색과 레이블은 제품 문맥에 맞춰 정하십시오. 예를 들어 실패율은 값이 높을수록 위험하지만,
상태 점수는 값이 높을수록 양호할 수 있습니다.

## 접근성

의미 있는 Meter에는 `Meter.Label`을 두거나 `aria-label`을 제공하십시오.
`format`, `locale`, `getAriaValueText`로 화면에 보이는 값과 스크린 리더의 설명을
같은 측정 단위로 맞출 수 있습니다.
