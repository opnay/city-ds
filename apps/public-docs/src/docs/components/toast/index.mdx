## 아이콘과 액션

앱 루트에 `Toaster`를 한 번 배치하고, 사용자 작업이 끝나는 곳에서 `toast()` 또는
`toast.success()` 같은 의미별 함수를 호출하십시오. `toast.error()`는 destructive tone으로
표현됩니다.

의미별 함수는 기본 아이콘을 표시합니다. `action`을 추가하면 가로 공간과 행동 우선순위를 위해
기본 아이콘만 자동으로 생략하며, `icon`으로 전달한 사용자 지정 아이콘은 유지합니다.

## 수명과 위치

기본값은 우측 하단, 최대 3개, 5초입니다. `Toaster`의 `position`, `visibleToasts`, `duration`으로
프로젝트 요구에 맞게 조정하십시오. 자동으로 닫지 않으려면 `duration={Infinity}`를 사용하십시오.
