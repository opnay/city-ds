## 조합

`Field`는 입력 UI가 아니라 하나의 폼 제어에 Label, Description, Error, disabled, invalid
문맥을 연결하는 컴포넌트입니다.

| 제어                                                          | Label 조합                                      |
| ------------------------------------------------------------- | ----------------------------------------------- |
| Input, Textarea, NumberInput, SearchInput, DatePicker, Select | 외부 `Field.Root`와 `Field.Label`을 사용합니다. |
| 입력형 Combobox                                               | 외부 `Field.Root`와 `Field.Label`을 사용합니다. |

입력 제어는 `Field.Root` 안에 배치하십시오. `Field.Control`은 일반 Input 대신 사용하는
래퍼가 아니라, 사용자 정의 제어를 Field 문맥에 합성할 때 사용합니다.

NumberInput, SearchInput, DatePicker 같은 합성 입력의 `disabled`와 `invalid` 상태는
Field의 레이블·오류와 입력 내부 제어가 함께 반영하도록 `Field.Root`와 입력 Root에 동일하게
전달하십시오.

## 접근성

Label을 생략하지 마십시오. Description과 Error는 제어의 설명 관계에 연결되어야 합니다.
